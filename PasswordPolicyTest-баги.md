# Баг-репорты

---
## [Длина пароля] Валидатор считает пароль в 64 символа не валидным, по спецификации разрешено 64 символа (граничное значение)
### Окружение:
junit5, gradle
### Шаги:
1. Передать пароль, соблюдающий все требования спецификации, например p2Lwh2CfhYN5xkYg7YWuT7rKR#2sBFYNTKZdpWT0i7RNK79PAw2MJsMeXWXxGmGe;  
2. Вызвать метод **_check()_**;
3. Вызвать метод **_isValid()_** у **PasswordPolicy.Result**, получаем **false**.
### Ссылка на спецификацию:
№3 длина больше 64
### Факт: 
Пароль не валиден.
### Ожидание:
Пароль должен считаться валидным.

## [Пароль слишком прост] Не учитывается регистр при проверке слишком простого пароля
### Окружение:
junit5, gradle
### Шаги:
1. Передать пароль, который является слишком простым с символами в верхнем регистре. Напрмер [PASSWORD, QWERTY, ADMIN, WELCOME]
2. Вызвать метод **_check()_**;
3. Вызвать метод **_isValid()_** у **PasswordPolicy.Result**, получаем **false**.
4. Проверить список нарушений, который отдает валидатор, должен содержать BLACKLISTED
### Ссылка на спецификацию:
№11 пароль совпадает с одним из простых:
password, qwerty, 123456, admin, welcome,
без учёта регистра
### Факт:
Пароль не содержит BLACKLISTED, проверка идет с учетом регистра.
### Ожидание:
BLACKLISTED должен вернуться, проверка должна быть регистронезависимой.

## [Кол-во допустимых символов идущих подряд] Последовательность из трех одинаковых подряд идущих символов считается валидной.
### Окружение:
junit5, gradle
### Шаги:
1. Передать пароль aaaAbBaAbB#1 
2. Вызвать метод **_check()_**;
3. Вызвать метод **_isValid()_** у **PasswordPolicy.Result**, получаем **true**.
### Ссылка на спецификацию:
№9 три и более одинаковых символа подряд
### Факт:
Пароль позволяет передать три подряд идущих одинаковых символов.
### Ожидание:
Три и более одинаковых символа должны возвращать REPEATED_RUN
